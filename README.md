# SUPERR
Cricket Pressure Intelligence is a static React dashboard. In frontend, run npm install, npm run dev or npm run build. For Vercel import the repository, select frontend as Root Directory, Vite as framework, npm install as install command, npm run build as build command and dist as output. The dashboard needs no API server or secrets.

Stage 4 supplies T20 and T20I metrics for High and Non-high pressure. Keep formats separate. Eligibility comes directly from the comparison exports. Dashboard ranks order eligible batters by descending high-pressure strike rate and bowlers by ascending high-pressure economy. Equal unrounded metrics tie. These views support review and do not constitute official final selections. Missing values display as an em dash. Stage 4 supplies match counts per player and situation, which cannot establish unique matches across the dataset.

The original backend is retained separately for its previous API consumers.
