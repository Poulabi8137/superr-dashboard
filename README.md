# SUPERR
Cricket Pressure Intelligence is a static React dashboard. In frontend, run npm install, npm run dev or npm run build. For Vercel import the repository, select frontend as Root Directory, Vite as framework, npm install as install command, npm run build as build command and dist as output. The dashboard needs no API server or secrets.

Overview and Pressure Leaderboard show the submitted RR Selector Season 2 report's pages 4 and 5. The roster stores published order, evidence labels and source IDs only. Metrics come from the original Stage 4 comparison exports, pooling High counts for T20 and T20I before division. The report states its 20-name dropdown restriction but only identifies the 16 distinct names represented in the final lists. Abdul Samad's published total combines two same-name IDs; this is reported explicitly. The assessment has no published deterministic scoring formula.

The format-specific batting, bowling, comparison and exploratory ranking views use the wider Stage 4 population. Their provisional sample screen and single-metric ranks are independent of report selection.

The original backend is retained separately for its previous API consumers.
